# CAGH UTM Website

Official website for University of Toronto Mississauga CAGH student chapter. Where admins can post events and students can sign up, recieving a confirmation email.

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Supabase
- Resend
- React Three Fiber / Three.js
- Framer Motion available for future animation work
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```


## Deploy
Push to GitHub and import the repository into Vercel.
