# CAGH UTM Website

A production-ready starter for the University of Toronto Mississauga CAGH student chapter.

## Stack
- Next.js (App Router)
- TypeScript
- Tailwind CSS
- React Three Fiber / Three.js
- Framer Motion available for future animation work
- Lucide icons

## Run locally
```bash
npm install
npm run dev
```

## Before launch
1. Replace the three placeholder application links in `src/lib/content.ts`.
2. Replace placeholder team names in `src/lib/content.ts`.
3. Replace placeholder event content with real dates and locations.
4. Replace the `EventPhoto` placeholders with authentic CAGH UTM photos.
5. Add your final logo/wordmark.

## Recommended photo files
Put optimized JPG/WebP images in `public/events/` and swap the placeholder component for `next/image` images.

## Deploy
Push to GitHub and import the repository into Vercel.
